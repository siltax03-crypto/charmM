# 🎞️ 참메모리 (CHARM Memory)

![SillyTavern Extension](https://img.shields.io/badge/SillyTavern-Extension-ff69b4) ![Version](https://img.shields.io/badge/version-0.1.0-blue) ![Language](https://img.shields.io/badge/UI-한국어-green)

솔직히 말해서, 롤플이 길어지면 캐릭터는 지난주에 한 약속도, 처음 손을 잡던 날도, 둘만 아는 농담도 다 잊어버립니다. 컨텍스트가 밀려나면 그걸로 끝이니까요.

**참메모리**는 SillyTavern용 장기 기억 확장입니다. 대화가 쌓이면 AI가 알아서 읽고 **기억·타임라인·주변 세계·캐릭터 심리**를 뽑아 저장하고, 매 턴 지금 장면에 필요한 것만 골라 캐릭터에게 다시 쥐여줍니다. 캐릭터가 "이전에 있었던 일"을 기억하게 됩니다.

* * *

## 무엇을 할 수 있나요?

| 기능 | 설명 |
|---|---|
| 🧠 **자동 기억 수집** | N개 메시지마다 대화를 읽고 💕마음·🔁습관·🤙약속·😲의외·💔상처·✨처음·🫶우리만의·🧭신념·🛡️불가침 9종 기억을 뽑아 저장 |
| 📅 **타임라인** | 사건을 연도 › 월 › 날짜로 정리. 사건에 딸린 사실(🎬 잔메모리)까지 함께 기록 |
| 🎯 **관련도 주입** | 매 턴 지금 대화와 관련된 기억만 골라 주입. 중요도·최근성·의미 유사도로 점수 매김 |
| 📌 **핀·중요도·흐릿해짐** | 중요한 기억은 핀으로 고정, 사소한 기억은 시간이 지나면 자연히 흐려짐 (삭제는 안 됨) |
| 🌾 **참결 (삶 보드)** | 캐릭터를 둘러싼 존재들 — 요즘의 그, 곁의 사람들(온도 게이지), 머무는 곳, 소중한 것, 세계 법칙 |
| 🪟 **마음의 창** | 수집할 때마다 캐릭터를 인터뷰해 속마음·비밀·후회·집착 등 13문항을 한국어로 기록 |
| 🔀 **분기 (외전·IF)** | 본편을 더럽히지 않고 외전 시나리오의 기억을 따로 관리 |
| 🩺 **지금 상태 · 🪨 지층** | (선택) 몸·사정·한계선을 매 턴 갱신하고, 기억을 문턱·결·피라미드 층으로 나눠 주입 |
| 💬 **물어보기** | "우리 처음 만난 날 뭐 했지?" 같은 걸 참메모리에게 직접 묻고, 답을 근거로 기억을 고침 |
| ⚙️ **도구 모음** | 중요도 재평가, 코어 정리, 챕터 요약, 회상 힌트, 한국어 번역, 집통소 순화, 백업·복원 |
| 🎨 **테마 5종** | 느와르·파우더 블루·블로섬·버터·ST 테마 추종 |

## 🚀 5분 시작 가이드

1. **활성화 + 자동 수집 켜기** — 확장 설정 ⚙️ 기본 항목. 기본은 5개 메시지마다 수집입니다.
2. **수집 AI 고르기** — 🤖 수집 AI 항목에서 Connection Manager 프로필을 고릅니다. 비워두면 메인 RP API를 씁니다.
3. **롤플 진행** — 전송 버튼 옆에 🎞️ 배지가 생깁니다. 숫자는 다음 자동 수집까지 남은 메시지 수입니다.
4. **기억 확인** — 채팅 입력창 왼쪽 🪄 확장 메뉴에서 **참메모리**를 누르거나 `/charm`을 입력하면 기억 모달이 열립니다.
5. **(권장) 임베딩 켜기** — 🔍 관련도 검색 → 임베딩(Gemini API)을 고르고 키를 넣은 뒤 **🔗 연결 테스트** → **📐 기존 기억에 임베딩 적용**을 누릅니다.

> **⚠️ 처음 쓰는 분이 꼭 알아야 할 것: 수집 후 옛 메시지가 자동으로 숨겨집니다.**
> 기억이 저장되면 마지막 6개를 남기고 이전 메시지가 `/hide` 처리되어 프롬프트에서 빠집니다. 채팅에서 사라진 게 아니라 접힌 것이고, 기억이 그 자리를 대신합니다. 마음에 안 들면 모달 하단 **↩ 되돌리기**가 직전 수집을 취소하고 숨김도 풀어줍니다.

## 📸 기능 둘러보기

### 🎞️ 전송 버튼 옆 배지

채팅 입력란 옆에 작은 배지가 붙습니다.

- **숫자** — 다음 자동 수집까지 남은 메시지 수
- **✦ (보라색)** — 이번 턴에 기억이 주입됨
- **… (초록색)** — 수집 진행 중
- **클릭** — 팝업이 열려 이번 턴에 주입된 기억을 보여줍니다. **＋** 버튼으로 지금 당장 수동 수집, **🔀** 버튼으로 분기 만들기, (📆 날짜별 요약을 켰다면) 달력 버튼도 여기 있습니다.

수집·임베딩이 도는 동안엔 🪄 마법봉 아이콘 위에 진행률이 겹쳐 표시됩니다. 모달을 닫아도 계속 보입니다.

### 💗 기억 모달

🪄 확장 메뉴 → **참메모리**, 또는 `/charm`. 기억·참결·마음의 창이 한 창의 탭으로 묶여 있습니다.

**코어 탭** — 카테고리별 기억 트리. 맨 위 ✨NEW는 직전 수집에서 새로 들어온 것.

| 카테고리 | 뜻 |
|---|---|
| 💕 마음 | 사랑하는 것, 심장이 멈칫한 순간 |
| 🔁 습관 | 반복되는 버릇·루틴 |
| 🤙 약속 | 한 약속. 클릭하면 **진행중 → 지킴 → 어김** 순환 |
| 😲 의외 | 예상을 깬 것 |
| 💔 상처 | 아팠던 것 |
| ✨ 처음 | 처음 있었던 일 |
| 🫶 우리만의 | 둘만 아는 것, 농담, 별명 |
| 🧭 신념 | 세상과 자신을 보는 방식 |
| 🛡️ 불가침 | 절대 넘지 않는 선, 맹세 |

각 기억 항목에서:
- **📌** 핀 고정 — 흐릿해지지 않고 항상 주입
- **✏️** 텍스트 편집 + 중요도 슬라이더 (1~10)
- **×** 삭제
- **☑️ 일괄 편집** — 여러 개 골라 중요도를 한 번에 조정

**타임라인 탭** — 연도 › 월별 사건 목록. 날짜를 클릭하면 수정할 수 있고, 항목을 클릭하면 🎬 잔메모리(그 사건에 딸린 사실: 누가 했나, 같이인지 혼자인지, 돈·물건·숫자)가 펼쳐집니다.

**하단 버튼**
- **↩ 되돌리기** — 직전 수집 취소 + 숨긴 메시지 복원
- **👁 미리보기** — 지금 이 턴에 주입될 내용 그대로 보기
- **📖 로어북** — 캐릭터 로어북을 기억으로 변환 / 기억을 로어북으로 내보내기 (비활성 엔트리는 제외)
- **💾 백업** — 저장 / 불러오기 (오늘 날짜 파일에 덮어쓰기)
- **🗑 전체삭제** — 이 캐릭터의 기억 전부 삭제 (주의!)

> **잠깐, 기억이 너무 많아지면 전부 주입되나요?**
> 아닙니다. 중요도 7 이상과 핀은 우선 주입되고, 나머지는 **관련도 × 중요도 × 최근성** 점수로 예산 안에서 경쟁합니다. 같은 기억이 3턴 연속 주입되면 2턴 쉬는 **재주입 쿨다운**도 있어서 한 기억이 대화를 독점하지 않습니다.

### 🔀 분기 (외전·IF)

"외전 1을 하는 동안 외전 2의 기억을 읽으면 안 된다"는 요구에서 나온 기능입니다. 모달 상단 탭 바에서 관리합니다.

| 만드는 법 | 종류 | 본편 기억 |
|---|---|---|
| 배지 팝업의 **🔀 갈림길** | 갈라진 분기 | 갈라진 시점까지의 본편 기억은 읽음 |
| 탭 바의 **＋** | 격리 분기 | 본편을 전혀 읽지 않는 빈 분기 |

- 탭 클릭 = 활성 분기 전환. 어느 탭이든 새 기억은 활성 분기에만 쌓입니다.
- 활성 분기 탭을 **다시 클릭**하면 그 분기를 본편으로 승격합니다. 본편 탭 재클릭은 이름 수정.
- 참결과 마음의 창도 분기를 따라갑니다. 되돌리기도 셋이 같이 돌아갑니다.

### 🌾 참결 (삶 보드)

참메모리가 **시간축**(무슨 일이 있었나)이라면 참결은 **공간축**(누가·어디서·무엇을 둘러싸고)입니다. 채팅 원문에서 직접 수집합니다.

- **🫀 요즘의 {캐릭터}** — 매 턴 항상 주입되는 근황
- **👥 곁의 사람들** — 주변 인물 카드. ⇄캐릭터·⇄유저 두 개의 온도 게이지(-100~+100)가 수집마다 조금씩 움직입니다. 🗂 시시콜콜을 펼치면 프로필·성격·말투·버릇·관계·서사
- **📍 삶이 머무는 곳** — 자주 가는 장소
- **💍 소중한 것들** — 추가만 되는 목록. 이야기에서 진짜 잃으면 조용히 사라집니다 (확인 팝업 없음)
- **📜 세계 법칙** — 이 세계의 규칙

**＋ 버튼** = 키워드 자동 등록. 이름만 적으면 채팅·참메모리·로어북을 뒤져 카드를 대신 씁니다.

> **참결은 전부 매 턴 주입되나요?**
> 요즘의 그만 항상 주입됩니다. 사람·장소·물건·법칙은 **지금 장면에 걸릴 때만** 무대에 오릅니다 — 최근 대화에 이름이 나오거나 의미 유사도가 높으면 3턴 동안 유지. 등장 안 한 NPC까지 매번 밀어넣지 않습니다.

### 🪟 마음의 창

수집할 때마다 캐릭터를 1인칭으로 인터뷰해 한국어로 기록합니다. 주입에는 쓰지 않는 **보기 전용**이라 롤플에 영향이 없습니다.

🫧 속마음 · 💗 나를 어떻게 보나 · 🫦 참고 있는 것 · 🃏 다음 수 · 💌 못 부친 편지 · 🥀 후회 · 🗝️ 비밀 · 🕸️ 거짓말 · 🌗 처음과 지금 · ⛓️ 집착 · 💤 꿈 · 🪦 내가 사라진다면 · 🕯️ 마지막 말

- 창 하나가 문항 하나. 클릭하면 이전 답들이 시간순으로 펼쳐집니다. 인터뷰는 이전 답을 이어받아 심화·전환합니다.
- **🔄 다시 묻기** — 지금 심리로 재인터뷰
- **🕰 지난 창** — 과거 구간만 보고 1회성 인터뷰 (지금의 창은 안 건드림)
- **🗂 회차 관리** — 잘못 생성된 회차 일괄 삭제

### 🎭 주입 방식 (ver1 · ver2 · ver3)

확장 설정 ⚙️ 기본 → **주입 방식**. 설정에 저장되어 PC와 폰이 같이 바뀝니다.

| 버전 | 내용 |
|---|---|
| **ver1** | 기본 주입. 처음엔 이걸로 시작하세요 |
| **ver2** | 🩺 **지금 상태**(생리 중, 감기, 냉전 중, 여행 중 같은 몸·사정·한계선)가 매 턴 주입되고 AI가 답변 끝에 직접 갱신. 예산을 글자 대신 토큰으로 |
| **ver3** | ver2를 품고 주입을 🚪문턱(둘 사이의 규칙) · 💗결(반복되는 감정의 결) · 🧬코어 · 📅피라미드(연/월/일 요약 카드) · 💬대목(요약이 손 안 댄 원문 대사) · 🔍줌인 층으로 나눔 |

ver2 이상이면 모달에 **🩺 지금** 탭이, ver3면 **🪨 지층** 탭이 생깁니다. 지층은 수집이 끝나면 자동 갱신되고(🪨 지층 자동 갱신), 💬 대목만 임베딩을 쓰기 때문에 지층 탭에서 직접 **대목 뽑기**를 눌러야 합니다.

### 💬 물어보기

기억 모달의 💬 탭. 정해진 메뉴가 아니라 대화창입니다. 참메모리가 필요한 만큼 기억·타임라인·채팅을 스스로 뒤져보고 답합니다.

- 기본 최근 40개 메시지만 읽고, 더 봐야 하면 **"전체 봐도 될까?"** 하고 물어봅니다.
- 기억을 고치자고 제안하면 **원문과 바뀔 문장을 나란히** 보여주고 승인을 받아야 적용됩니다.
- 묻고 고치는 일이라 🤖 수집 AI 항목의 **💬 물어보기 AI**에 높은 모델을 따로 지정하는 것을 권합니다.
